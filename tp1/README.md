# Trabajo Práctico N.º 1 — ALU

## Descripción

Este trabajo presenta el diseño y la implementación en Verilog de una unidad aritmético-lógica (ALU) parametrizable. El circuito realiza ocho operaciones aritméticas, lógicas y de desplazamiento. Su funcionamiento se verificó mediante un testbench con comprobación automática, compuesto por casos dirigidos y entradas pseudoaleatorias. Finalmente, el diseño se sintetizó, se implementó y se probó sobre una placa de desarrollo Digilent Basys 3, equipada con una FPGA Artix-7.
