# TP3 — Matriz de cobertura de verificación

- **Tipo:** matriz de verificación.
- **Estado documental:** matriz vigente del plan de verificación; pruebas diseñadas, sin ejecutar.
- **Base:** requisitos y contratos vigentes.

## Propósito y alcance

Este documento define la matriz de cobertura de la verificación. La matriz relaciona cada requisito con los bloques, invariantes y pruebas que permiten comprobarlo, sin confundir la existencia de una prueba diseñada con la ejecución exitosa del hardware.

El alcance comprende:

- El inventario de los 167 requisitos actuales.
- La cobertura de los 54 bloques definidos por sus interfaces.
- La cobertura de las 25 invariantes arquitectónicas.
- Los enlaces entre cada requisito, su fuente primaria y las pruebas correspondientes.
- La identificación de todas las variantes que pertenecen a cada prueba.

Cada prueba se describe una sola vez, incluso cuando cubre varios requisitos. Las filas correspondientes enlazan con esa descripción y con todas sus variantes. La fuente primaria orienta la lectura de cada contrato; los contratos adicionales continúan siendo válidos y se consideran tanto en el requisito como en las pruebas.

La matriz también incluye comprobaciones documentales, de timing y de placa. Estas aportan evidencia sobre esos aspectos, pero no se consideran simulaciones funcionales de la CPU.

## Perfiles y riesgos críticos

| Alcance                              | Cobertura finita                                                                                                                                                                                                                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| REFERENCE funcional                  | Todos los vectores dirigidos, salvo los locales con otra capacidad explícita.                                                                                                                                                                                                                                 |
| ALT_1000                             | PLAT-001; MEM-003/004 para límites; UART-004 para carga mínima/completa; UART-008 para lista con último byte y capacidad completa; UART-014 para plazos. EXEC-002 comprueba la preparación con capacidad 1000. Los demás vectores locales de ISA/hazards no necesitan duplicarse si no dependen de capacidad. |
| Capacidad mínima / máximo aritmético | PLAT-001, MEM-003/004, EXEC-002, UART-004/008; 2^32 se verifica en funciones/checkers, sin arrays físicos obligatorios.                                                                                                                                                                                       |
| Precisión y antigüedad               | PIPE-008/010, EXEC-004/005/006, ISA-008.                                                                                                                                                                                                                                                                      |
| Aislamiento de sesión                | MEM-008, EXEC-002/007/010, UART-004/005/011.                                                                                                                                                                                                                                                                  |
| Consumo RX con TX ocupada            | UART-009/014; El retiro y descarte de RX no dependen de los flags de TX.                                                                                                                                                                                                                                      |
| Observación y final físico           | UART-007/008/009/011/012/013.                                                                                                                                                                                                                                                                                 |
| Inyección artificial                 | PIPE-004/007; MEM-003/004/006; EXEC-001/009 y fila FSM local de EXEC-006; fixtures UART-002/003/005/007/008/009/012 y reconocimiento local durante drains en UART-013. No acredita alcanzabilidad normal.                                                                                                     |
