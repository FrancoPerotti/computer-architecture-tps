No evalúa el estilo contra una norma externa ni propone cambios al código.

## Metodología

1. Enumerar archivos con `rg --files --hidden`, respetando exclusiones, y separar por extensión y ubicación. El inventario incluye el árbol de trabajo, no solamente archivos ya comprometidos en Git.
2. Repetir con `--no-ignore` para detectar copias importadas y salidas de Vivado; clasificar por directorio y función antes de contar evidencia.
3. Leer fuentes y realizar búsquedas transversales de declaraciones, nombres, bloques procedurales, tareas, semillas, timeouts, excepciones, imports, señales, etiquetas y configuración. Revisar estructura y formato de todas las familias incluidas.
4. Comprobar nombres de módulo/archivo y recurrencias mecánicas por archivo; usar el AST de Python para contrastar la presencia parcial de anotaciones. Comparar las dos ALU normalizando comentarios, espacios y `timescale`, sin afirmar igualdad byte a byte.
5. Contrastar cada hallazgo con sus excepciones y redactar la guía con el mismo alcance. Distinguir una práctica general, un patrón de un subsistema y una observación de un único archivo.

Comandos para reproducir la enumeración desde la raíz:

```sh
rg --files --hidden -g '!**/.git/**' -g '*.sv' -g '*.py' -g '*.tcl' -g '*.sh' -g '*.xdc'
rg --files --hidden --no-ignore -g '!**/.git/**' -g '*.sv' -g '*.v' -g '*.py' -g '*.tcl' -g '*.sh' -g '*.xdc'
rg --files --hidden -g '!**/.git/**' -g '*.tex' -g '*.qss' -g '*.svg'
```

Las cantidades de la matriz cuentan archivos que contienen el patrón, salvo que se indique otra unidad. Una coincidencia textual no mide calidad ni garantiza comportamiento funcional. En recurrencias cualitativas como idioma o alineación, los ejemplos muestran el patrón y sus variaciones sin atribuirles un porcentaje no medido.

## Validación y límites del análisis

Se cotejaron las listas de este informe con la enumeración de fuentes: cubren los 53 archivos propios, las 28 fuentes LaTeX y los tres SVG sin duplicados dentro de cada inventario. Se verificaron las recurrencias cuantitativas de módulo/archivo, `always_comb`, tareas, comparaciones, contadores, semillas, timeouts, `timescale`, atributos de sincronización y anotaciones Python. Los fragmentos de la guía se contrastaron literalmente con sus archivos de origen y los enlaces locales se comprobaron contra el árbol actual.

La matriz contiene 25 identificadores de hallazgos. La guía utiliza los de organización y SystemVerilog (G1–G4 y SV1–SV8) y limita las observaciones generales a su alcance RTL y de bancos de prueba. Ambos documentos distinguen fuentes implementadas y ejemplos futuros. La comprobación de cambios se limita a estos documentos y a su presentación en el README; se conserva la fila de TP3 que ya estaba modificada y los archivos existentes de ese trabajo.

No se ejecutaron síntesis, simulaciones RTL, pruebas Python ni compilación LaTeX para este cambio documental. No se modificaron fuentes ni se revisó la corrección funcional de sus algoritmos. Los resultados describen el árbol inspeccionado y no prometen uniformidad en versiones futuras. La ausencia de una configuración de formato permite describir lo observado, pero no atribuir preferencias no registradas a sus autores.
